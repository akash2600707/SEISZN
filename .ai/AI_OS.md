# SEISZN AI Operating System (SAIOS)

## Mission

Build India's smartest Gen Z fashion platform focused on confidence through accurate sizing, modern UX, affordability, and customer trust.

---

## Core Philosophy

Every implementation must improve at least one:

- Conversion
- Customer Trust
- Customer Happiness
- Operational Efficiency

If not, don't build it.

---

## Engineering Principles

- Mobile First
- Server Components First
- Type Safety
- Accessibility
- Performance
- Security
- Cost Awareness

---

## Cost Strategy

Always prefer free-tier solutions.

Upgrade only when business growth requires it.

Avoid vendor lock-in.

---

## Architecture

Modular Monolith

One Repository

One Deployment

One Database

Feature Modules

---

## Never

- Redesign architecture
- Refactor unrelated code
- Install packages without approval
- Delete existing features
- Guess requirements

---

## Always

Read documentation first.

Explain implementation plan.

Implement.

Test.

Update documentation.

Stop.

---

## Coding Rules

- TypeScript Strict
- Tailwind CSS
- Next.js App Router
- Server Actions where possible
- Reusable Components
- Zod Validation
- React Hook Form
- Clean Architecture

---

## Success

Every feature should increase

- Conversion
- Trust
- Customer Happiness
